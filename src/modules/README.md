# Doménové moduly

Etapa 2: `identity` obsahuje Drizzle model účtu/profilu, ověření identity a autorizovanou transakční službu. SQL migrace mají jedinou historii v `supabase/migrations`.

Dokumenty, postupy, výrobky, sklad a soubory se přidají v příslušných etapách. UI, služby a přístup k datům zůstávají oddělené. Žádné předčasné doménové tabulky.
